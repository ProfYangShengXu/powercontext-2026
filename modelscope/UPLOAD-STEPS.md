# 上传步骤（给没有技术背景的人）

要上传的文件已经准备好了，就在这个目录里：**`llm-prompt-caching.zip`**。
下面三步照做即可，不用装任何软件，也不用改任何文件。

---

## 第 1 步 · 登录并进入 Skills 中心

1. 浏览器打开：**https://modelscope.cn/skills**
2. 用**队伍指定的那个账号**登录。⚠️ 别用个人账号——页面地址里的 `owner` 就是登录账号，评委按它找。
3. 页面上找「发布」「新建 Skill」「+」之类的按钮点进去（叫法可能略有不同，位置一般在 Skills 列表右上角）。

## 第 2 步 · 填表、上传压缩包

| 页面上的字段 | 填什么 |
| --- | --- |
| `skill_name`（技能名） | `llm-prompt-caching` —— **一字不改**，只能小写字母、数字、连字符，**建好后改不了** |
| 显示名 / display_name | `LLM 前缀缓存工程` |
| 简介 / description | 复制下面那段话，不要改写 |
| 分类 / category | `developer-tools` |
| 许可证 / license | `MIT` |
| 文件 / 上传 | 选本目录下的 **`llm-prompt-caching.zip`** —— **不要解压，也不要重新压缩** |

简介那段（整段复制）：

> 讨论或调优 LLM 缓存命中率、设计 agent 的 prompt 结构、读 provider 返回里的缓存计数时使用。含词元级与请求级两个命中率口径、三段式 prompt 铁律、断点放置与失效清单、各家开关差异，以及用返回字段自证命中的方法。

填完点「发布 / 提交」，等页面提示成功。

## 第 3 步 · 复制地址，回填大赛平台

发布成功后，**二选一，只填一个**：

- **网址**：打开这个 Skill 的详情页，把地址栏整条链接复制下来，形如
  `https://modelscope.cn/skills/<owner>/llm-prompt-caching`
- **编号**：`<owner>/llm-prompt-caching`

自查（30 秒）：开一个**无痕窗口**（不登录）把复制的值粘进去，**能看到 SKILL.md 正文**才算对。
然后回大赛测试平台，进「魔搭社区」入口，把**同一条值**粘进去提交；提交后看页面显示的值，要和刚才复制的**一字不差**（大小写、`/` 的个数都算）。

---

## 上传前 30 秒，先确认三件事

1. **别动这个 zip。** 改内容要重新打包，一旦根目录多套了一层文件夹，平台就读不到正文——上传会"成功"，但页面是空的。
2. **别用个人账号。** `owner` 对不上，评委按编号打开就是别人或 404。
3. **发出去基本收不回。** 删除只能在这个网页的控制台里做，接口删不了。上面三处确认无误再点发布。

## 卡住了怎么办

| 现象 | 怎么办 |
| --- | --- |
| 找不到「发布」按钮 | 在 Skills 列表页右上角找「+」或头像菜单里的「发布 / 创建」 |
| 提示技能名已被占用 | 这个账号已经建过同名 Skill。去列表里找那条旧的，**不要改名重建**（旧的删不掉，会变成两条） |
| 提示文件不合格 | 找位会用命令行的同事，在**本目录**执行 `unzip -l llm-prompt-caching.zip`：根层必须直接是 `SKILL.md` 和 `references/`，不能多一层文件夹 |
| 发布成功但页面没有正文 | 同上一条，九成是 zip 根层多套了一层目录；重新打包再传一次（旧的删不掉就改名重建） |

## 上传成功之后

- 把**网址或编号**记下来（建议同时截图详情页），填进大赛平台的对应入口；
- 本地 `modelscope/` 目录整个保留，别删——下次重交直接复用；
- `scrub-2026-10-31.txt` 是上传前的脱敏自检记录（内容为空表示没有命中任何敏感项），一起留着备查。
